# data/

No external datasets are required by this repository — every turbulence
model is a first-principles/analytic implementation parameterized by
Cn2, wavelength, and link geometry (all passed in directly by the
caller), not fit to or loaded from measured data. This directory is a
placeholder for future work: e.g. cached ERA5/CAMS climatology inputs
(consistent with the CAQC channel-model work referenced in the project's
broader research context) or measured Cn2 profiles for validating a
specific ground station.
