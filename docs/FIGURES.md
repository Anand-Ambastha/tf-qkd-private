# FIGURES.md — Figure Index and Reproduction

All figures are generated by `src/plotting.py` (consistent serif
typography, 300 DPI raster + vector PDF, shared style via `_style()`) and
saved to `figures/` as both `.png` and `.pdf` (git-ignored scratch folder). The committed, canonical copies for the current release are in `results_v2.3.0/figures/`. Every figure is reproducible by re-running the corresponding example; the committed copies are a snapshot of that output.

## Reproducing everything

```bash
pip install -r requirements.txt
python3 examples/example_01_model_comparison.py   # PDF overlay across turbulence regimes
python3 examples/example_02_adaptive_alpha.py      # (numeric only, no figure)
python3 examples/example_03_distance_sweep_and_validation.py  # distance sweep + validation table
python3 examples/example_06_gamma_gamma_per_arm_validation.py # per-arm GG vs LN max range, 10 figures (QUICK=1 for a fast smoke run)
```

## Additional figure functions available (not wired into the bundled
## examples, but ready to call directly)

- `plot_channel_pdf(channel, out_dir=..., name=...)` / `plot_channel_cdf(...)`
  — single-model PDF/CDF, used internally by `TurbulenceChannel.plot_pdf()`
  / `.plot_cdf()`.
- `plot_mc_convergence(rows)` — takes the output of
  `monte_carlo.benchmark_monte_carlo` (see docs/PERFORMANCE.md for the
  underlying numbers) and renders estimate-vs-N with error bars plus a
  runtime-vs-N log-log panel.
- `plot_quadrature_benchmark(rows)` — same, for
  `quadrature.benchmark_quadrature`'s Gauss-Legendre order sweep.

Example (not bundled as a separate script, but a direct call):

```python
from src.turbulence import GammaGammaChannel
from src.monte_carlo import benchmark_monte_carlo
from src.plotting import plot_mc_convergence
ch = GammaGammaChannel(0.05, 3e-15, 1550e-9, 6000)
rows = benchmark_monte_carlo(ch, lambda eta: eta, sample_grid=[100,1000,10000,100000])
plot_mc_convergence(rows, out_dir='figures', name='my_mc_convergence')
```

## What's intentionally not included

Per-figure SVG export and a fully populated `notebooks/` walkthrough were
descoped for this delivery (see README.md "Scope and honest limitations")
— every figure function saves PNG+PDF, which covers both presentation and
publication-vector use cases; SVG can be added trivially to `_save()` in
`plotting.py` (one more `fig.savefig(..., format='svg')` line) if needed.
