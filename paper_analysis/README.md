# paper_analysis — tables, figures and LaTeX for the TF-QKD turbulence paper

Everything here is generated by the scripts in `scripts/` from the repository code (`src/`, `analytical_validation/`).
Nothing in `src/` or `analytical_validation/` was changed. Run all commands from the repository root with
`numpy scipy matplotlib mpmath` installed and `pdflatex` available for the PDFs.

## Layout

```
paper_analysis/
├── scripts/      code that produces every table, figure and .tex below
├── results/
│   ├── tables/   CSV/JSON data
│   └── figures/  PNG/PDF figures
└── latex/
    ├── paper_content/       main write-up (tables + full derivation) .tex and .pdf
    └── sensitivity_study/   controlled sigma_X^2 sensitivity study .tex and .pdf
```

## What each script does

| Script | Output | Content |
|---|---|---|
| `gg_beamwander_table.py` | `results/tables/gg_beamwander_table.csv` | Gamma-Gamma (per arm) key rate without / with beam wander (long-term beam broadening), Cn2 = 1e-17, 1e-15, 1e-13, L = 20-160 km |
| `ln_vs_gg_per_arm.py` | `ln_vs_gg.csv`, `perarm_analytic.csv` | Log-normal vs Gamma-Gamma key rate at equal per-arm Rytov variance (`perarm_analytic.csv` is an earlier R-only version, kept for reference) |
| `perarm_analytic_errors.py` | `perarm_analytic2.csv` | Per-arm Gamma-Gamma: mean / 2nd / 3rd / 4th-order analytic errors of e_X, e_Z, R, with and without beam wander |
| `sensitivity_study.py` | `sensitivity.csv` | Controlled study: sigma_X^2 imposed at L = 80, 120, 160 km, for LN, GG, GG+BB (324 cases) |
| `sensitivity_thresholds.py` | `sensitivity_thresholds.json` | Thresholds (0.1 % / 1 %) and maxima derived from `sensitivity.csv` |
| `sensitivity_figures.py` | `results/figures/sens_fig_{LN,GG,GGBB}.pdf/png` | 3-panel error-vs-sigma_X^2 figures |
| `sensitivity_make_tex.py` | `latex/sensitivity_study/tfqkd_sensitivity_study.tex` | Fills `doc_template.tex` with the tables |
| `ln_error_vs_distance.py` | `ln_errors_cut.csv`, `results/figures/ln_error_{eX,eZ,R}_cut_800dpi.png/pdf` | Log-normal relative error vs L, cut where the key rate at the expansion point reaches zero (232.5 km); 800 dpi |
| `paper_make_tables.py`, `paper_assemble_tex.py` | `latex/paper_content/*.tex` | Builds the main write-up from the repo tables in `analytical_validation/results/tables/` plus the CSVs above; `derivation.tex` is hand-written |

## Reproduce

```bash
pip install numpy scipy matplotlib mpmath
for s in gg_beamwander_table ln_vs_gg_per_arm perarm_analytic_errors sensitivity_study ln_error_vs_distance; do
  python3 paper_analysis/scripts/$s.py; done                 # about 5-10 min in total
python3 paper_analysis/scripts/sensitivity_thresholds.py
python3 paper_analysis/scripts/sensitivity_figures.py
python3 paper_analysis/scripts/sensitivity_make_tex.py
python3 paper_analysis/scripts/paper_make_tables.py && python3 paper_analysis/scripts/paper_assemble_tex.py
(cd paper_analysis/latex/paper_content && pdflatex tfqkd_paper_content.tex)
(cd paper_analysis/latex/sensitivity_study && pdflatex tfqkd_sensitivity_study.tex)
```

## Conventions and caveats

* Errors are `100 (approx - reference) / reference` in percent. References are independent of the formulas: Simpson / Gauss-Hermite quadrature in X = ln(eta/eta0) for log-normal; numerical convolution of the two arms' Bessel-K log-densities for per-arm Gamma-Gamma.
* Gamma-Gamma shape parameters use `(sigma_R^2)^(6/5)` for `sigma_R^(12/5)` (as the repository code since v2.2.0). The progress report used `(sigma_R^2)^(12/5)`.
* "Beam wander" = turbulence-induced long-term beam broadening (`src/turbulence/beam_broadening.py`), applied per arm as a shift `eta0 -> eta0 * f_bb`; the fading law is unchanged.
* The sensitivity study imposes sigma_X^2 independently of distance. It is a controlled sensitivity study, not a set of atmospheric conditions; Gamma-Gamma cannot exceed Var(X) = 0.858 (saturation), so the grid stops at 0.8.
* The unclipped analytic formulas are only meaningful while the key rate at the expansion point is positive; for the log-normal channel at Cn2 = 1e-17 that ends at 232.5 km (deterministic key rate: 252 km).
